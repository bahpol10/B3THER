## دربارهٔ اپ

**بهمن** اپ VPN اندرویدی خودمه که از
[Aether Mobile](https://github.com/QW-AI-Code/Aether)
(ساختهٔ QW-AI-Code / Cluvex Studio) فورک شده و با یک رابط کاربری ساده‌تر و
مدرن‌تر بازسازی شده: طراحی گرافیتی و فیروزه‌ای برقی، دکمهٔ اتصال بزرگ و
متحرک، آمار زندهٔ اتصال و هیچ چیز اضافه‌ای. موتور زیرش همون هستهٔ
Aether (نسخهٔ 2.4.0) ـه — همون تونل امتحان‌پس‌داده، با ظاهر خودم.

## امکانات

- **شش حالت اتصال** — ‏Aether (WARP)، ‏Aether → Psiphon، ‏Tor، ‏Aether → Tor،
  ‏Tor → Psiphon و Tor → Aether؛ بسته به اینکه شبکه‌ت چی رو اجازه می‌ده مسیر رو عوض کن.
- **کارت آمار زنده** — تایمر جلسه، IP خروجی با پرچم کشور، سرعت لحظه‌ای
  دانلود و آپلود، مسیر اتصال و پینگ.
- **تونل جداگانه برای هر اپ** — خودت انتخاب کن کدوم اپ‌ها از VPN رد بشن.
- **کلید قطع اضطراری (Kill Switch)** — اگه تونل قطع بشه، ترافیک هم قطع می‌شه.
- **تنظیمات DNS، ‏MTU، فرگمنتیشن و ECH** برای شبکه‌های سخت‌گیر.
- **تایل تنظیمات سریع و ویجت صفحهٔ اصلی** — اتصال با یک لمس.
- **دستیار Gemini** — با کلید API رایگان خودت از Google AI Studio.
- **رابط فارسی و انگلیسی** با پشتیبانی کامل از راست‌به‌چپ.
- **لاگ تشخیصی رمزنگاری‌شده** — برای رفع اشکال بدون لو دادن جزئیات.

## دانلود

## ساخت از سورس

- **گیت‌هاب اکشن** — هر پوش روی `main` به‌صورت خودکار APKها رو می‌سازه و
  به‌عنوان Release منتشر می‌کنه (`.github/workflows/build.yml`).
- **اندروید استودیو** — پروژه رو باز کن، بذار گریدل سینک بشه و اجرا کن.
  موتور نیتیو با `scripts/build-natives.sh` ساخته می‌شه (به NDK و Rust نیاز
  داره)؛ راهنمای کامل ساخت و امضا توی `README-B3HMAN.md` هست.
